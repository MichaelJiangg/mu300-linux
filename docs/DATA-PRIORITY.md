# 异步应用数据业务偏好

平台 `mobile-data` 完成原有射频初始化后，启动独立后台任务，依次尝试：

```text
AT+CEUS=1
AT+CEMODE=2
```

- **不是拨号前置条件**：拨号不等待后台任务。已经联网也可设置，不会因此
  断开 PDP、重新拨号或重启射频。
- 每条指令以成功通信且最后一条非空回复为 `OK`、无 ERROR/CME/CMS 错误
  为确认依据，不仅凭客户端退出码判断。这里确认的是设置命令的 OK，
  不额外发送 CEUS?/CEMODE? 回读。
- 未确认成功的指令最多重试 **3 次**（加上首次发送，每条最多 4 次），
  收到 OK 立即停止该条重试；第一条重试耗尽仍处理第二条。
  耗尽只记失败日志，不冒充成功，也不阻断拨号。后台任务启动失败也不
  阻断拨号，不增加固定启动等待或无限重试。
- 使用选定上网 SIM 的 `SPACTCARD`，通过共享通道 nr1/nr4 发送，避开
  nr2/nr5 拨号专用通道。每条命令响应预算 3 秒、客户端锁预算 1 秒，
  仅后台任务承担这些等待；守护进程不在时禁止退回直接打开 tty。
- 开机预热、拨号、切换上网卡后的拨号、恢复射频共用此入口；同一卡的
  重叠后台任务合并，不用持久化“已完成”标记跳过后续启动。
- 与可选 LuCI 锁定回放解耦，清除锁定或关闭回放不取消此策略。
- 原有射频初始化本身的错误仍按原有错误处理，不与偏好命令失败混淆。

OpenWrt（含 TF/Magisk 的 6.x、7.x）与 systemd rootfs 使用同一份平台
overlay，安装包必需文件清单也包含 `mobile-data`。已有旧包不会自动更新。
