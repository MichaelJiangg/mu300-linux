# U30 Air 灯控适配与后续修正（2026-10-16）

## 约定行为

- 网络灯：4G 蓝色，5G 白色，无服务红色。
- Wi-Fi 灯：5 GHz 白色，2.4 GHz 蓝色。
- 电池灯：充电时蓝色硬件呼吸，充满后白色；未充电且电量低于或等于 15% 时红色闪烁。
- 外部供电期间，按用户启用设置保持三组灯工作；拔电后重新开始熄灯倒计时。用户主动关闭某组灯的设置仍然有效。
- 电池灯亮度可在网页调整；网络灯和 Wi-Fi 灯是开关型硬件，不提供无效的亮度选项。

## 本次后续修正

此前呼吸曲线为 1250/250/1250/750 ms（渐亮/峰值保持/渐暗/暗处保持），周期 3.5 秒。现改为 625/750/625/250 ms，周期 2.25 秒：加快节奏、延长最亮阶段，提高一轮内的平均亮度。默认峰值保持硬件允许的 255，不提升 PMIC 电流或超出额定亮度。

拔电时，充电器 online 已更新为 0，但电量计 status 可能短暂仍为 Charging/Full；现以实际外部供电状态为准，避免继续显示充电呼吸。

旧脚本没有把电源快照、状态文件及灯硬件写入放在同一事务内，存在电源事件和超时熄灯交错执行的机会。现使用已有 flock 依赖串行化 U30 Air 的灯控操作，取得锁后才读取供电状态。后台温度告警不持有该锁，避免长期阻塞。未增加轮询或软件呼吸任务。

## 验证

- 25 项灯控、网页设置、机型识别相关测试通过，包含拔电后电量计状态滞后、超时后再次收到电源事件、事件等待锁时发生拔电等情况。
- 已热部署到连接的 U30 Air，无需重启。
- 实机硬件曲线回读为 `0 625 255 750 0 625 0 250`；PMIC 峰值寄存器为 `0xffff`，曲线寄存器为 `0x0505` / `0x0206`。
- 通过临时 LED 测试输入模拟“已拔电但电量计仍报 Charging”，充电呼吸立即清除。模拟计时到期后，三组灯均回读 0，PMIC RGB 控制寄存器回读 0；随后恢复真实电源输入和正常灯控。
- 模拟测试没有修改充电器、网络、AT、NV 或分区配置。实际拔插的长期稳定性仍需日常使用观察。

当前 U30 Air 管理地址为 `192.168.77.1`。这些源码和热部署改动尚未重打安装包。
