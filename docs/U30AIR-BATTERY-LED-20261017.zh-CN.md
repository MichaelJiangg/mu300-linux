# U30 Air 电量灯颜色

按照用户确认的原厂实机行为调整；本轮未另行逆向原厂灯控程序或实机部署。

| 状态 | 低于 50% | 50% 及以上 |
| --- | --- | --- |
| 非充电，灯仍在显示时间内 | 蓝色常亮 | 白色常亮 |
| Charging | 蓝色呼吸 | 白色呼吸 |
| Full | 白色常亮 | 白色常亮 |

保留原硬件呼吸周期、亮度设置、充电保持点亮、拔电重置显示倒计时、过期熄灭、迟到事件互斥和热告警。移除普通低电量红闪分支，避免与原厂的 50% 分色规则冲突。网页 LED 配置的中英土说明同步修改。

只作用于 U30 Air 的电池灯；F50、V50 的独立灯控不变。没有新增轮询或动画进程。离线测试覆盖 0 / 15 / 49 / 50 / 51 / 100%、蓝白硬件呼吸切换、Full 停止呼吸和已有插拔熄灭时序。本次未更新此前发布包。
