# MU300 公共问题同步与扩散验证

日期：2026-10-17。基于维护中的 `clean-tf-7.2`，本轮工作分支为 `fix/shared-issues-20261017`。对应 E5 仓库本轮 issue 修复，逐项核对可复用部分；未修改上游分支。

## 实际修复

### 1. 内置分区正常扩容被误判失败

MU300 的 Android 独立分区写入、利用未分配空间安装，以及 initramfs 离线扩容，都要求 ext4 的块数与目标容量完全一致。但 `resize2fs` 遇到不足以容纳元数据的末尾小块组时，可以成功扩容而不使用这段尾部空间。原检查会把这种合法结果当成失败。

三个路径共用 `desktop/boot/ext4-geometry.sh`。成功扩容且只读 fsck 通过后，接受目标块数或目标内最后一个完整块组边界；仍拒绝大幅欠扩容、越界、错误块大小及无效块组。不会把大分区上残留的旧 2 GiB 文件系统认作成功。

助手脚本已接入电脑端载荷上传和 initramfs 构建。缺失依赖会在写入前失败。保留设备身份、分区大小、镜像摘要、邻接区域和 GPT 检查；利用空闲空间的路径仍在文件系统验证成功后提交 GPT。显式不扩容选项保持有效。

新脚本不放进影响续装载荷身份的工具目录；测试确认仅新增该脚本不会改变原有关键载荷身份，不会无故拒绝待完成的续装记录。发布包普通文件清单仍校验它。

### 2. Wi-Fi 页面提供驱动不支持的密码套件

原生 LuCI 列出 GCMP、GCMP-256、CCMP-256 等选项，但不核对当前无线芯片能力。新增只读能力查询，按当前 radio 对应 PHY 的 IEEE 密码套件编号筛选候选项。其他无线芯片按各自能力显示；查询失败保持原有选项，不能把能力未知误认成不支持。

扩散检查同时覆盖 E5 侧曾发现的关联问题：若旧配置用了不支持的套件，直接移除选项会让原生 select 自动选择 `auto`。现在保留当前旧值并标记不支持，保存时明确提示用户主动选择合法项，避免修改热点名称时顺带改变密码套件。

查询使用现有 ucode、ubus、iw 和随固件提供的 BusyBox；不新增 Python 运行依赖、服务或常驻轮询。只打开无线配置弹窗时查询，不进入基带启动链。中英土三语言提示均验证。

干净 rootfs 构建、插件安装及首次初始化已接入同一补丁器；重复执行不会重复修改。源文件结构不符合预期时不写入半成品。移除可选看板插件前，会撤销本轮对原生 LuCI 的引用；测试确认恢复后的无线页面与原文件字节一致。

## 未照搬的部分

- MU300 无实体屏幕，不移植 E5 屏幕锁屏、唤醒和导航代码。
- 原生 TF/Magisk 安装直接格式化后解包，不经过上述镜像扩容检查，原生安装文件未改动。
- MU300 使用自带工具链，不存在 E5 对 Magisk BusyBox 路径的同一依赖问题。
- E5 的充电器和 TF 电源时序属于不同硬件实现，未复制到 MU300/U30 Air。
- 未更改 AT 顺序、开机回放、基带重连、NV、无线内核驱动或运行时省电策略。本轮不增加正常开机的 fsck 或轮询。

## 扩散验证

23 组 unittest 共发现 **197 项：195 项通过，2 项跳过，无失败**。另有真实 Chromium 原生 select 验证通过。

覆盖范围包括：

- 真实 ext4 临时稀疏文件：完整扩容、合法尾部省略、欠扩容拒绝、证明文件保留，以及实际 initramfs 扩容函数。
- 真实临时 loop、挂载及 GPT：相邻区域保护、摘要失败不提交 GPT、GPT 被改变时提前退出，以及不扩容选项。所有块写入仅针对测试临时文件。
- 安装器、启动镜像、启动链、TF 格式化与容量检查、续装身份、更新互斥锁。
- 隔离 ARM64 容器执行实际 ucode：能力解析、真实 ubus 缺 radio 的失败分支、实际打包 LuCI 源码补丁、幂等与卸载还原、异常源码不被部分写入。
- Chromium 执行实际 LuCI `ui.Select`：三语言、三种不支持的旧套件、其他 PHY 能力及查询失败；验证旧值不会自动变为 `auto`。
- U30 Air 灯光、PD、充电控制、V50 灯光、热点、信道和 USB 稳定性相关回归。保留本轮开始前已有的 U30 Air 灯光更改。

两项跳过的原因：现有信道测试的 `MU300_WRT_IMAGE` 可选在线工具安装用例未启用；启动链的“非 root 必须拒绝”用例在 root 测试环境下按原测试规则跳过。不能将它们计为已验证。新增密码套件测试使用独立的离线容器环境变量，已实际执行。

验证期间另修正两个测试环境问题：BusyBox 内建 `ip` 绕过 PATH 桩，改为显式测试函数；充电容器未运行系统初始化，补建 `/run` 并等待测试监听器就绪。这些修改仅在测试夹具中，没有改充电或 USB 运行代码来迎合测试。

详细执行日志和汇总位于忽略目录 `work/shared-issues-20261017/`，最终汇总为 `FINAL-VERIFICATION.json`。`git diff --check` 通过。

## 验证边界

本轮为源码修改和离线扩散验证，未连接设备写入、刷机、修改 NV 或重打发布包。源码提交不代表已验证发布包或实机结果。实际无线接入、特定存储设备的电气稳定性不能由本轮离线结果替代。密码套件筛选不构成对 WPA3 固件密钥来源安全性的重新认证，也未改动此前的 SAE 桥接实现。
